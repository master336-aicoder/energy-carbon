1认证方式

JWT Bearer Token 认证

所有接口（除登录外）均需在请求头中携带 JWT Token：

Authorization: Bearer <accessToken>

Token 有效期：7200 秒（2小时），过期后可使用 refreshToken 刷新

2通用响应格式

成功响应

{ "code": 200, "message": "操作成功", "data": { ... } }

失败响应

{ "code": 500, "message": "错误信息", "data": null }

分页响应

{ "code": 200, "message": "操作成功",
  "data": {
    "current": 1, "size": 10, "total": 100,
    "records": [ ... ]
  }
}
