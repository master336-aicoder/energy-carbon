## 1. 概述

### 1.1 项目背景

能碳数智化平台移动端一期（V1.0）已上线运行，覆盖了登录认证、首页仪表盘、数据录入（指标/产量/抄表）、告警中心、报表查看、个人中心、扫码等基础功能。经过一期用户的实际使用反馈，现启动二期建设，重点围绕以下方向进行能力升级：

- **增强数据录入能力**：一期仅支持基础的指标、产量、抄表录入，二期扩展能源采购、碳排放因子等更多业务场景的录入能力，同时强化离线录入、批量操作、OCR 识别等效率工具。
- **丰富报表展示**：一期报表仅支持预设报表的简化版只读查看，二期增加多时间维度切换、同比环比对比、成本分析、设备能效等专业报表，并支持导出与订阅。
- **新增设备巡检功能**：从一期的基础巡检录入升级为完整的巡检任务管理体系，涵盖任务分配、模板化检查、异常上报（含 GPS 定位）、巡检统计等闭环流程。
- **告警能力增强**：新增告警订阅、静默时段、趋势分析、照片取证等高级功能。
- **消息中心统一入口**：整合告警消息、系统通知、任务提醒，建立统一消息中心。
- **个人中心增强**：新增数据统计概览、收藏夹、操作日志、主题切换、多语言等功能。

### 1.2 二期设计目标

| 目标编号 | 目标描述 | 验收标准 |
|---------|---------|---------|
| G1 | **录入提效** | OCR 识别准确率 >= 95%，批量导入效率提升 50% 以上 |
| G2 | **报表专业度** | 支持日/周/月/年四维度切换，同比环比对比图表展示完整 |
| G3 | **巡检闭环** | 巡检任务从分配到执行到上报到统计全流程线上化，完成率可追溯 |
| G4 | **消息统一** | 告警、通知、任务三类消息统一入口，支持分类筛选和跳转处理 |
| G5 | **体验升级** | 支持亮色/暗色主题切换，中英文双语，界面交互一致性提升 |

### 1.3 技术方案延续

二期延续一期技术栈，新增以下能力支持：

| 技术点 | 一期方案 | 二期增强 |
|--------|---------|---------|
| 前端框架 | UniApp（Vue 3）+ uView UI | 引入 uCharts 图表库（报表图表） |
| 本地存储 | uni.setStorage + SQLite | 扩展离线数据表结构，支持批量导入临时存储 |
| 图片处理 | 压缩上传 OSS/COS | 新增 OCR 识别（调用云端 OCR API） |
| 推送服务 | 极光推送 / 个推 + 微信订阅消息 | 增加消息分类和静默时段控制 |
| 定位服务 | uni.getLocation | 巡检场景增强 GPS 轨迹记录 |
| 导出能力 | 无 | H5 端 PDF/Excel 下载，小程序端文件分享 |

## 2. 用户画像

### 2.1 用户角色定义（二期更新）

在一期用户角色基础上，根据二期新增功能扩展角色职责和使用场景。

| 角色 | 职责描述（二期更新部分标粗） | 典型使用场景 | 使用频率 |
|-----|--------------------------|------------|---------|
| **现场抄表员** | 负责定期到各计量点抄写表码，**使用 OCR 识别表码、批量导入产量数据** | 现场拍照识别表码、按产线分组批量录入产量 | 每日多次 |
| **设备巡检员** | 负责用能设备的日常巡检与异常上报，**按巡检任务执行标准化检查、GPS 定位上报异常** | 接收巡检任务 → 到达现场 → 逐项检查 → 异常拍照定位上报 | 每日多次 |
| **能源管理员** | 负责能耗数据监控、告警处理、报表查看，**录入能源采购数据、配置告警订阅** | 录入能源采购单、查看能耗对比报表、设置告警静默时段 | 每日 |
| **碳排放管理员** | 负责碳排放数据采集与核算支撑，**维护碳排放因子库** | 录入/更新排放因子、查看碳排放趋势报表 | 每周多次 |
| **企业管理层** | 关注整体能碳指标与减排进度，**订阅关键报表、查看成本分析** | 在手机端查看月度成本报表、碳排放趋势、订阅日报推送 | 每周 |

### 2.2 二期新增用户旅程地图（以巡检员为例）

```
接收任务推送 --> 查看今日巡检任务清单 --> 前往巡检点
     ↑                                          │
     │                                          ▼
  巡检统计看板 <--- 查看巡检历史 <--- 提交巡检结果
                                              │
                                    ┌─────────┴──────────┐
                                    ▼                    ▼
                              全部正常              发现异常
                                                    │
                                                    ▼
                                              拍照 + GPS 定位
                                                    │
                                                    ▼
                                              填写异常描述
                                                    │
                                                    ▼
                                              提交异常上报
```

### 2.3 痛点与期望（二期补充）

| 痛点 | 期望的二期解决方案 |
|-----|------------------|
| 抄表时手动输入表码易出错、效率低 | OCR 拍照自动识别表码，减少手动输入 |
| 产量数据需逐条录入，工作量大 | 按产线/车间分组批量导入，支持模板下载 |
| 巡检无统一标准，结果难以量化对比 | 巡检模板化检查清单，巡检结果可统计 |
| 报表功能单一，无法深入分析 | 多维度报表切换、同比环比对比、趋势分析 |
| 告警推送频繁打扰休息时间 | 告警订阅 + 静默时段，只接收关心的告警 |
| 收藏的报表/设备找不到快捷入口 | 个人中心提供"我的收藏"功能 |

## 4. 二期功能模块清单

│  增强数据录入（能源采购/排放因子/产量增强/OCR）    │
├─────────────────────────────────────────────────┤
│  丰富报表展示（多维对比/趋势/成本/能效/导出/订阅） │
├─────────────────────────────────────────────────┤
│  设备巡检（任务管理/模板检查/GPS上报/统计）       │
├─────────────────────────────────────────────────┤
│  告警增强（订阅/静默/趋势/照片取证）              │
├─────────────────────────────────────────────────┤
│  消息中心（统一消息/分类/详情跳转/推送设置）       │
├─────────────────────────────────────────────────┤
│  个人中心增强（概览/收藏/日志/主题/多语言）        │
└─────────────────────────────────────────────────┘

## 7. 非功能需求

### 7.1 性能需求（二期补充）

| 指标 | 目标值 | 说明 |
|-----|-------|------|
| OCR 识别响应时间 | <= 3 秒 | 从拍照到返回识别结果（P95） |
| OCR 识别准确率 | >= 95% | 数字表码识别正确率 |
| 报表图表渲染时间 | <= 500ms | 单图表首次渲染完成 |
| 报表导出时间 | <= 10 秒 | PDF/Excel 文件生成（标准月报） |
| 批量导入处理 | <= 500 条/次 | 单次产量批量导入上限 |
| 消息列表加载 | <= 300ms | 50 条消息首屏渲染 |

### 7.2 兼容性需求

二期兼容性要求与一期保持一致，参见 V1.0 文档第 8.2 节。

### 7.3 安全需求（二期补充）

| 需求编号 | 需求内容 | 实现方式 |
|---------|---------|---------|
| SEC-08 | OCR 图片传输加密 | 图片上传采用 HTTPS + 签名校验，识别完成后服务端不保留原图 |
| SEC-09 | 报表导出权限控制 | 仅允许导出用户权限范围内的报表数据 |
| SEC-10 | GPS 位置数据保护 | 位置信息仅在巡检上报时传输，不缓存历史轨迹 |
| SEC-11 | 操作日志防篡改 | 个人操作日志仅记录不可删除，保留 90 天 |

### 7.4 可靠性需求（二期补充）

| 需求编号 | 需求内容 | 指标 |
|---------|---------|------|
| REL-06 | OCR 服务可用性 | >= 99.5%（依赖第三方 OCR 服务 SLA） |
| REL-07 | 批量导入成功率 | >= 99%（排除数据格式错误） |
| REL-08 | 离线数据同步失败重试 | 最多自动重试 3 次，间隔 30 秒递增 |

### 7.5 用户体验需求（二期补充）

| 需求编号 | 需求内容 |
|---------|---------|
| UX-07 | 报表图表手势交互：支持双指缩放、左右滑动查看更多数据点 |
| UX-08 | 批量导入进度反馈：上传后实时展示导入进度条（已处理 N/M 条） |
| UX-09 | OCR 识别反馈：识别过程中展示加载动画，结果返回后以动画填入表单 |
| UX-10 | 暗色模式：全局切换时图表颜色、图片边框等细节同步适配 |
| UX-11 | 多语言：界面文案统一通过 i18n 配置文件管理，支持热切换无需重启 |
| UX-12 | 消息已读状态同步：一端已读，多端同步（App + 小程序 + PC） |
| UX-13 | 巡检进度可视化：巡检执行页顶部展示进度条和完成百分比 |

### 7.6 运营与统计需求（二期补充）

| 需求编号 | 需求内容 | 说明 |
|---------|---------|------|
| OPS-06 | OCR 使用统计 | OCR 调用次数、识别成功率、修正率 |
| OPS-07 | 批量导入统计 | 导入次数、成功/失败分布、常见错误类型 |
| OPS-08 | 报表使用统计 | 各报表访问量、导出量、订阅量 |

### 10.1 术语表（二期补充）

| 术语 | 说明 |
|-----|------|
| OCR | Optical Character Recognition，光学字符识别，用于识别表盘数字 |

| tCO2e | 吨二氧化碳当量，碳排放计量单位 |
| 排放因子 | Emission Factor，单位活动水平产生的温室气体排放量 |
| 范围一排放 | Scope 1，企业直接拥有的或控制的排放源产生的温室气体排放 |
| 范围二排放 | Scope 2，企业外购电力、蒸汽、供暖或制冷产生的间接排放 |
| 范围三排放 | Scope 3，价值链上下游的间接排放 |
| 静默时段 | 用户设定的免打扰时间区间，非危急告警在此时段内不推送 |
