### 1. sys_user（系统用户表）

| 项目 | 内容 |
|------|------|
| **表名** | sys_user |
| **中文名** | 系统用户表 |
| **用途** | 存储系统登录用户信息，包括管理员和普通用户 |
| **数据量预估** | 100-10000条 |

**字段清单：**

| 字段名 | 类型 | 长度 | 是否必填 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| id | BIGINT | - | 是 | 自增 | 主键ID |
| username | VARCHAR | 50 | 是 | - | 用户名（唯一） |
| password | VARCHAR | 100 | 是 | - | 密码（BCrypt加密） |
| nickname | VARCHAR | 50 | 否 | - | 用户昵称 |
| phone | VARCHAR | 20 | 否 | - | 手机号 |
| email | VARCHAR | 50 | 否 | - | 邮箱 |
| avatar | VARCHAR | 200 | 否 | - | 头像URL |
| dept_id | BIGINT | - | 否 | - | 所属部门ID |
| status | TINYINT | - | 否 | 1 | 状态（1正常 0停用） |
| create_time | DATETIME | - | 否 | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | - | 否 | CURRENT_TIMESTAMP | 更新时间 |
| create_by | BIGINT | - | 否 | - | 创建人ID |
| update_by | BIGINT | - | 否 | - | 更新人ID |

**索引：**

| 索引名 | 字段 | 类型 |
|--------|------|------|
| PRIMARY | id | 主键 |
| idx_username | username | 普通索引 |
| idx_dept_id | dept_id | 普通索引 |
| idx_status | status | 普通索引 |
