H5 构建产物为纯静态资源，可直接部署到现有 Nginx 服务器。

**Nginx 配置示例**

```nginx
server {
    listen 80;
    server_name mobile.your-domain.com;
    
    # 移动端H5静态资源
    location / {
        root /usr/share/nginx/html/energy-carbon-mobile;
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    
    # API 代理（复用现有后端服务）
    location /api/ {
        proxy_pass http://localhost:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        proxy_connect_timeout 30s;
        proxy_send_timeout 30s;
        proxy_read_timeout 30s;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # Gzip压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
}
```

**部署步骤**

```bash
# 1. 构建H5
cd energy-carbon-mobile
npm run build:h5

# 2. 复制构建产物到Nginx目录
sudo cp -r dist/build/h5/* /usr/share/nginx/html/energy-carbon-mobile/

# 3. 重载Nginx配置
sudo systemctl reload nginx
```

#### 9.2.2 微信小程序上传到微信后台

**前置条件**
- 已注册微信小程序账号
- 已完成企业主体认证
- 已配置服务器域名（request、downloadFile、uploadFile）

**上传步骤**

1. 使用微信开发者工具打开 `dist/build/mp-weixin`
2. 点击右上角 `上传` 按钮
3. 填写版本号和项目备注
4. 上传成功后，登录[微信小程序后台](https://mp.weixin.qq.com)
5. 进入 `管理` -> `版本管理` -> `开发版本`
6. 点击 `提交审核`，填写审核信息
7. 审核通过后，点击 `发布`

**服务器域名配置**

在小程序后台 `开发` -> `开发管理` -> `开发设置` -> `服务器域名` 中配置：

| 类型 | 域名示例 | 说明 |
|------|----------|------|
| request合法域名 | `https://api.your-domain.com` | API请求域名 |
| downloadFile合法域名 | `https://static.your-domain.com` | 图片/文件下载域名 |
| uploadFile合法域名 | `https://api.your-domain.com` | 文件上传域名 |

### 9.3 移动端配置

#### 9.3.1 API 地址配置

移动端通过 `manifest.json` 和运行时配置管理 API 地址。

**manifest.json 基础配置**

```json
{
  "name": "世通能碳管理",
  "appid": "__UNI__XXXXXXXX",
  "description": "世通AI+能碳管理平台移动端",
  "versionName": "1.0.0",
  "versionCode": "100",
  "transformPx": false,
  "app-plus": {
    "usingComponents": true
  },
  "mp-weixin": {
    "appid": "wxXXXXXXXXXXXXXXXX",
    "setting": {
      "urlCheck": false
    }
  }
}
```

**API 地址配置文件**

建议创建 `src/config/env.js`：

```javascript
// 环境配置
const ENV = {
  // 开发环境
  development: {
    BASE_URL: 'http://localhost:8080',
    API_PREFIX: '/api',
    UPLOAD_URL: 'http://localhost:8080/api/common/upload'
  },
  
  // 测试环境
  test: {
    BASE_URL: 'https://test-api.your-domain.com',
    API_PREFIX: '/api',
    UPLOAD_URL: 'https://test-api.your-domain.com/api/common/upload'
  },
  
  // 生产环境
  production: {
    BASE_URL: 'https://api.your-domain.com',
    API_PREFIX: '/api',
    UPLOAD_URL: 'https://api.your-domain.com/api/common/upload'
  }
};

// 根据编译条件获取当前环境
// #ifdef H5
const currentEnv = process.env.NODE_ENV === 'production' ? 'production' : 'development';
// #endif

// #ifndef H5
// 小程序和App通过manifest或运行时判断
const currentEnv = 'production';
// #endif

export default ENV[currentEnv];
```

#### 9.3.2 环境切换

**H5 环境切换**

H5 构建时通过 `vite` 环境变量控制：

```bash
# 开发环境
npm run dev:h5

# 生产环境
npm run build:h5
```

在 `vite.config.ts` 中配置环境变量：

```typescript
import { defineConfig, loadEnv } from 'vite';
import uni from '@dcloudio/vite-plugin-uni';

export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd());
  
  return {
    plugins: [uni()],
    define: {
      'process.env': {
        BASE_URL: env.VITE_BASE_URL,
        API_PREFIX: env.VITE_API_PREFIX
      }
    }
  };
});
```

**小程序环境切换**

小程序无运行时环境变量概念，建议：

1. 在 `src/config/env.js` 中通过条件编译区分：

```javascript
// #ifdef MP-WEIXIN
const BASE_URL = 'https://api.your-domain.com';
// #endif
```

2. 或者通过开发者工具详情页配置 `请求域名`

**App 环境切换**

App 端可通过以下方式切换环境：

1. 在 `manifest.json` -> `app-plus` 中配置自定义参数
2. 在 App 启动时读取本地配置文件（如 `config.json`）
3. 通过应用内设置页面手动切换环境（仅测试包启用）

#### 9.3.3 多端条件编译说明

UniApp 支持通过条件编译处理多端差异：

| 条件编译写法 | 说明 |
|-------------|------|
| `#ifdef H5` | 仅H5平台生效 |
| `#ifndef H5` | 除H5外所有平台生效 |
| `#ifdef MP-WEIXIN` | 仅微信小程序生效 |
| `#ifdef APP-PLUS` | 仅App生效 |
| `#ifdef APP-PLUS || APP-PLUS-NVUE` | App平台生效 |

**示例**

```javascript
// 仅在App端调用原生推送
// #ifdef APP-PLUS
uni.getPushClientId({
  success: (res) => {
    console.log('推送CID：', res.cid);
  }
});
// #endif

// 仅微信小程序使用订阅消息
// #ifdef MP-WEIXIN
wx.requestSubscribeMessage({
  tmplIds: ['xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx'],
  success: (res) => {}
});
// #endif
```
