# 能碳数智化管理平台 v0.0.01 升级说明

**升级日期**: 2026-06-27

## 升级内容

### 后端修复
1. **RBAC权限控制完善**
   - `AuthController.userinfo` 接口：不再硬编码返回 roles/permissions，改为从数据库查询用户角色和权限菜单
   - 超级管理员（角色id=1）返回 `menus: ["/"]` 标识显示所有菜单
   - 普通用户通过 `sys_user_role` + `sys_role_menu` + `sys_menu` 三表联查获取权限菜单
2. **新增缺失的 Mapper XML 文件**
   - `SysMenuMapper.xml` - `selectMenuTreeByUserId` SQL实现
   - `SysUserRoleMapper.xml` - `selectRoleIdsByUserId` SQL实现
   - `SysRoleMenuMapper.xml` - `selectMenuIdsByRoleId` SQL实现
3. **新增 SysUserService.getUserRoles 方法**
   - 通过 `@Select` 注解联表查询 `sys_role` + `sys_user_role`
4. **修复用户详情接口返回角色信息**
   - `SysUserController.getById` 现在返回用户关联的角色列表

### 前端修复
1. **Dashboard路由路径修复**
   - `DefaultLayout.vue` 菜单 index 拼接逻辑修正，首页不再跳转到 `/dashboard/dashboard`
2. **用户名刷新后丢失修复**
   - `user store` 增加 `userInfo` 的 localStorage 持久化
   - 路由守卫中检测到 token 存在但 userInfo 为 null 时自动调用 `fetchUserInfo()` 恢复
3. **RBAC菜单权限过滤修复**
   - `DefaultLayout.vue` 兼容后端返回的字符串格式 menus（如 `["/"]`）和对象格式
4. **数据类型下拉统一**
   - 创建 `constants/monitor.ts` 共享数据类型常量（13种类型）
   - `History.vue`、`DeviceCompare.vue`、`TimeCompare.vue` 统一使用英文 value
5. **Knowledge.vue bug修复**
   - `showUploadDialog` → `uploadDialogVisible`
   - `loadList()` → `loadData()`

### 部署变更
- Nginx 端口从 80 改为 19999

## 升级步骤

### 1. 执行数据库升级脚本
```bash
mysql -u root -p energy_carbon < upgrade.sql
```

### 2. 停止后端服务
```bash
killall java
```

### 3. 替换后端 jar
```bash
cp energy-carbon-admin-master336.jar /opt/energy-carbon/app/app.jar
```

### 4. 部署前端
```bash
cd /opt/energy-carbon/frontend/
rm -rf *
tar -xzf admin-dist.tar.gz
```

### 5. 修改 Nginx 端口
```bash
# 修改 /etc/nginx/nginx.conf 或 /etc/nginx/conf.d/energy-carbon.conf
# listen 80 -> listen 19999
nginx -t && nginx -s reload
```

### 6. 启动后端服务
```bash
cd /opt/energy-carbon/app/
nohup java -jar app.jar --spring.profiles.active=prod > backend.log 2>&1 &
```

## 回滚方案
保留上一版本的 `app.jar.bak` 和前端备份，如需回滚：
```bash
cp app.jar.bak app.jar
# 恢复旧前端
cd /opt/energy-carbon/frontend/
rm -rf *
tar -xzf admin-dist-backup.tar.gz
killall java
nohup java -jar app.jar --spring.profiles.active=prod > backend.log 2>&1 &
```
